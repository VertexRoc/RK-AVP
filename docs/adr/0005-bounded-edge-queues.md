# ADR-0005: 每Edge独立有界队列

- 状态：Accepted
- 日期：2026-08-11

## 背景

一个Node可能同时连接实时预览、推理和网络分支。共享Node inbox会把不同分支的容量和丢帧语义合并，慢AI可能反压主码流。

## 决策

每条Edge拥有独立有界队列、`block/drop_oldest/drop_newest`策略和指标。Executor任务队列同样有界。

## 后果

- 分支可以独立控制延迟和丢帧。
- 内存上限可以由图配置推导。
- Graph运行时需要维护更多队列状态和EOS/Bound传播。
- 队列策略成为业务图必须审查的配置。

## 替代方案

每Node一个无界或共享队列。该方案实现简单，但无法满足多媒体实时流控要求。
